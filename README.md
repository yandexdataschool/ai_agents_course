# AI-агенты — курс ШАД, осень 2026

Семь занятий по вторникам, 03.11–15.12.2026. Каждое занятие — лекция и синхронный семинар.
На семинарах вместе собираем агента интернет-магазина: домен retail из [τ²-bench](https://github.com/sierra-research/tau2-bench),
агента пишем сами, без фреймворков.

## Как устроен репозиторий

```
weekNN_topic/
  README.md                       тема, дата, лектор, о чём лекция и семинар
  lecture/slides.pdf              слайды лекции (после занятия)
  seminar/seminarNN_tasks.ipynb   ноутбук с TODO — выкладывается перед занятием
  seminar/seminarNN_solutions.ipynb   ноутбук с решениями — после занятия
```

Ноутбуки рассчитаны на Google Colab: кнопка «Open in Colab» есть в README каждого занятия.

## Модель и доступ

На курсе одна модель — Qwen3.6-35B-A3B, провайдера каждый выбирает сам (Yandex Cloud AI Studio, OpenRouter, своя машина).
Ноутбуки читают адрес, ключ и имя модели из секретов Colab `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`.
Подробная инструкция по доступу к модели — в `setup.md` (скоро).
