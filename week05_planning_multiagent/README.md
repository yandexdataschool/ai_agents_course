# Занятие 5. Долгие задачи (планирование) и мультиагентность

**Дата:** 01.12.2026 (вт) · **Лектор:** Саша Куваев

## Лекция

Длинные траектории и планирование (где живёт план, восстановление после ошибок); субагенты для изоляции контекста; паттерны оркестрации и режимы отказа мультиагентных систем; протоколы A2A, ACP.

Слайды: `lecture/slides.pdf` — появятся после занятия.

## Семинар

Планирование: длинная операционная задача («разбери все возвраты за неделю»), план-туду и перепланирование после ошибок. Мультиагентность: оркестратор + субагенты, критик перед необратимым действием, хэндофф по ролям. Честное сравнение с одним агентом по успеху и стоимости.
